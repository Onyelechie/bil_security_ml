Edge Enrollment

Enroll Edge Device

Generate the Ed25519 keypair on the edge PC, keep the private key there, and paste only the public key here. Use the same value for `EDGE_PC_ID` and `DEVICE_ID` on the edge machine.

Identity rule

`EDGE_PC_ID` and `DEVICE_ID` must match. The enrolled public key will be tied to that same id.

The dashboard will call `/api/devices/enroll` on the active target.

Operator Flow

Provisioning Checklist

  1. Generate the Ed25519 keypair on the edge PC.
  2. Keep the private key on the edge PC only.
  3. Unlock admin access for the active server target.
  4. Enroll the public key here using the final edge/device id.
  5. Set `EDGE_PC_ID`, `DEVICE_ID`, and `DEVICE_PRIVATE_KEY_B64` on the edge machine.
  6. Start the edge agent and confirm heartbeat appears on the server.
Recommended practice Let the edge generate the keypair locally. The dashboard should receive only the public key.
